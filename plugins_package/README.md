# Plugin Barbershop Pro (Tiệm Cắt Tóc Nam)

Đây là thư mục chứa mã nguồn của plugin `Barbershop Pro` dành cho Easy!Appointments.

## Cấu trúc Plugin:
- `plugin.json`: Chứa thông tin mô tả, tác giả, màu sắc nhận diện (`#c59b27`), tên thương hiệu.
- `services.json`: Chứa toàn bộ 5 nhóm danh mục và 20 dịch vụ làm tóc nam chuẩn kèm giá tiền và thời lượng.

## Cách sử dụng:
1. Để cài đặt plugin này vào hệ thống, bạn có thể nén toàn bộ thư mục `barbershop` này thành file `barbershop.zip`.
2. Hoặc sử dụng luôn file `barbershop.zip` đã được đóng gói sẵn trong thư mục này.
3. Đăng nhập trang Quản trị (Admin) > Vào mục **Plugins** > Bấm chọn file `barbershop.zip` và bấm **Tải lên & Cài đặt**.
4. Sau khi cài đặt xong, bấm nút **[ Kích hoạt Plugin ]** để áp dụng toàn bộ giao diện và dịch vụ tiệm tóc!
